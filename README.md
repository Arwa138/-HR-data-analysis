# HR Data Analysis

This project analyzes HR data using SQL, Python, and Tableau to uncover insights into employee attrition, salary distribution, and performance trends.

## 📊 Tools Used
- **SQL Server** – data extraction and transformation
- **Python (Pandas, Seaborn, Matplotlib)** – data cleaning and EDA
- **Tableau** – interactive dashboards

## 📁 Dataset
The dataset contains:
- Employee ID
- Department
- Age
- Gender
- Job Role
- Salary
- Hire Date
- Attrition
- Performance Rating

Source: Cleaned CSV uploaded manually.

## 🧪 Python Analysis
The notebook `HR Final Result.ipynb` covers:
- Data Cleaning (nulls, dtypes, renaming)
- Exploratory Data Analysis (correlations, visualizations)
- Insights into attrition by department and gender
- Salary & performance trends

## 🔍 Goals
- Understand employee turnover patterns
- Visualize key HR metrics
- Provide actionable insights for HR decisions
